# Tech Stack

## Core
- **Framework**: [Next.js 14.2.23](https://nextjs.org/) (App Router)
- **Language**: [TypeScript 5.7.2](https://www.typescriptlang.org/)
- **UI Library**: [React 18.3.1](https://reactjs.org/)

## Backend & Database
- **ORM**: [Prisma 5.22.0](https://www.prisma.io/)
- **Database**: PostgreSQL
- **Server Logic**: Next.js Server Actions

## Styling & UI
- **CSS Framework**: [Tailwind CSS 3.4.17](https://tailwindcss.com/)
- **Icons**: [Lucide React 0.468.0](https://lucide.dev/)
- **Post-processing**: PostCSS, Autoprefixer

## Development & Tooling
- **Runtime**: Node.js
- **Execution**: [tsx](https://github.com/privatenumber/tsx) (for scripts and seeds)
- **Linting**: ESLint (config-next)
- **QA**: Custom responsive QA script (`scripts/qa-responsive.mjs`)
